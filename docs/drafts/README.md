# Drafts

Anything in this folder is kept in the repository but **not published**.
`exclude_docs` in `mkdocs.yml` drops the whole folder at build time.

Use it for pages that are still half-written, or for notes that should stay
private but are worth versioning alongside the rest of the wiki.

To publish one, move it into `docs/guides/` (or `projects/`, `products/`,
`references/`) and add it to the `nav` in `mkdocs.yml`.
